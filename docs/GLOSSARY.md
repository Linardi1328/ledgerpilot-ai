# Glossary

| Term | Meaning |
| --- | --- |
| AccountingPlatformGateway | Planned provider-independent boundary for exporting approved accounting entries to accounting platforms. |
| AI recommendation | Suggested extraction, classification, coding, or review input generated by an AI or rule-assisted process. It is untrusted until validated. |
| Approval | Human decision accepting a reviewed accounting outcome within authority. |
| Audit event | Attributable record of an action, decision, transition, or integration result. |
| Chart of accounts | Structured list of general-ledger accounts available for posting. |
| Client entity | Client organisation or business served by an accounting firm. |
| Correction | Attributable change that preserves previous values/history. |
| Cost centre | Optional reporting dimension used for management reporting or allocation. |
| Deterministic accounting control | Rule or validation that produces predictable results independent of AI judgement. |
| Document abstraction | Logical representation of an uploaded file, version, metadata, extracted fields, and related workflow. |
| Duplicate detection | Process for identifying possible repeated documents, invoices, or external postings. |
| Field confidence | Confidence or uncertainty information for extracted values. |
| Human review | Accountant or senior reviewer evaluation of evidence, recommendation, risk, and accounting outcome. |
| Idempotency | Property that retrying an export/submission does not duplicate external effects. |
| LHDN | Inland Revenue Board of Malaysia. |
| MyInvois | Malaysian e-Invoice system operated by LHDN; future integration direction only in Phase 0. |
| Rejection | Human decision declining a document or accounting recommendation with reason. |
| Reversal | Controlled accounting action that reverses an approved accounting effect. |
| Risk indicator | Flag that signals uncertainty, duplicate risk, high value, unusual activity, low confidence, or policy exception. |
| SQL Account | Proposed first accounting-platform integration target. |
| Supersession | Controlled replacement of an approved record while preserving prior history. |
| Tenant | Firm-level ownership boundary in the application. |
| Untrusted input | Data that must be validated before being accepted, including AI output. |
